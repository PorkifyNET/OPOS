OPOS 0.6.5: OPOS Recovery, so a broken start no longer means losing everything.

- OPOS Recovery is a new screen for fixing OPOS without the command line. Open it from the new "OPOS Recovery" entry in the start menu, from Settings > UPDATES > RECOVERY, or let it open by itself after 3 starts in a row that did not finish. An administrator signs in first.
- UNDO THE LAST UPDATE puts back the version you had before the last update. You can undo again to return to the newer one.
- REPAIR SYSTEM FILES checks the system files and replaces damaged or missing ones.
- RESCUE MY FILES copies your accounts' files to a USB stick or another drive.
- SAFE START starts OPOS once with the basic display mode, sound muted and no update checks. RESET SETTINGS puts the display, appearance and desktop settings back to their defaults (accounts, files and programs stay). RESET A PASSWORD sets or removes an account's password.
- START-UP LOG shows what happened during this start and the one before.
- The installation media has a new REPAIR button that fixes an installed OPOS that no longer starts.

The "OPOS Recovery" start menu entry is added the first time 0.6.5 starts.

Updating from 0.6.3 or older: VMware may hang at the restart at the end of the update. The update is already installed by then. Close VMware, end vmware-vmx.exe (taskkill /F /IM vmware-vmx.exe from an administrator command prompt; this stops every running VM) or restart Windows, then start the VM again.
