OPOS 0.1.2: the first release with a web browser.

- New web browser (run /bin/browser URL): HTTP and HTTPS, HTML, CSS layout (flex, grid, media queries, custom properties) and TrueType text.
- Browser: text selection and copy, find in page (Ctrl+F), a certificate error page.
- Browser forms: text fields, multi-line text areas, check boxes, radio buttons, drop-down lists, and GET and POST submission.
- Terminal: 1000 lines of scrollback and text selection with the mouse.
